# ECE Admin (Flutter)

لوحة إدارة عربية لبيانات شاشة ECE عبر PocketBase (نفس قاعدة `ECE-screen`).

## المتطلبات

- Flutter 3.29+ (Web و/أو Windows)
- تشغيل `ECE-screen` بحيث PocketBase يستمع على `http://0.0.0.0:8090`
- حساب **superuser** (الذي أنشأته من رابط `pbinstall` أول مرة)

## التشغيل

```bash
cd admin
flutter pub get
flutter run -d chrome
# أو على ويندوز:
flutter run -d windows
```

عند الدخول أدخل عنوان السيرفر، مثلاً:

- نفس الجهاز: `http://127.0.0.1:8090`
- من جهاز آخر على الشبكة: `http://IP-الشاشة:8090`

## ماذا تدير؟

الجداول، المراحل، الشعب، الشريط، الأساتذة، الإعلانات، الوسائط — إضافة / تعديل / حذف، مع رفع ملفات للوسائط والصور.

## ملاحظة أمان

الدخول بحساب superuser. لا تفتح المنفذ 8090 على الإنترنت العام بدون حماية.
